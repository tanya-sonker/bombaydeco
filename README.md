# bombaydeco
An interactive heritage map of Mumbai's Art Deco buildings. Name inspired by the book *[Bombay Deco](https://www.architecturaldigest.in/story/bombay-deco-is-the-ultimate-chronicle-of-mumbais-art-deco-history/)*.

**Status:** Proof of Concept - Bandra subset, 87 buildings.

**Live:** [bombaydeco.art](https://bombaydeco.art)
